# Контент-завод

Конвейер производства контента, которым можно управлять из облачной сессии
Claude Code — в том числе с телефона.

## Быстрый старт в новой сессии

1. Открыть сессию на этом репозитории.
2. Ввести `/start` — Claude восстановит контекст из `docs/STATE.md`.
3. Работать.
4. Ввести `/finish` — Claude зафиксирует состояние, обновит журнал и запушит.

## Что где лежит

- `CLAUDE.md` — правила работы и карта проекта, читается автоматически
- `docs/STATE.md` — где мы сейчас (источник правды)
- `docs/PROJECT.md` — что делаем и для кого
- `docs/ROADMAP.md` — этапы
- `docs/JOURNAL.md` — журнал сессий
- `docs/DECISIONS.md` — принятые решения и их причины
- `content/` — идеи → черновики → опубликованное
- `templates/` — шаблоны форматов
- `.claude/` — хук автозагрузки контекста и команды `/start`, `/finish`, `/idea`

> Контейнер облачной сессии временный: всё, что не закоммичено, пропадает.
