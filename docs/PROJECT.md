## Пайплайн

```
idea → draft → review → final → published
 ↓       ↓                        ↓
content/ideas  content/drafts   content/published
```

Правила перехода между стадиями:

- **idea → draft**: у идеи есть тезис и понятно, кому она полезна.
- **draft → review**: текст целиком, без дыр `[[проверить]]`.
- **review → final**: факты проверены, тон выдержан, заголовок сформулирован.
- **final → published**: опубликовано, файл перенесён в `content/published/` с датой.

## Definition of Done для единицы контента

- [ ] Тезис ясен с первого абзаца
- [ ] Нет непроверенных фактов и выдуманных цифр
- [ ] Заголовок и первый абзац переписаны минимум один раз
- [ ] Есть призыв/следующий шаг для читателя
- [ ] Файл лежит в правильной папке, имя по формату `ГГГГ-ММ-ДД-имя.md`
